# Datasets

* [in-toto LinkML schema](in-toto-linkml-schema.md) - The LinkML schema of the in-toto Attestation Framework, `src/in_toto_linkml/schema/in_toto_linkml.yaml` (schema id `https://w3id.org/lmodel/in-toto`, version 1.2.0) with its modules `in_toto_core` and `in_toto_predicates`: 32 classes, two enums and one type. Its `lokf adapt` copy `.lokf/in-toto.yaml`, rooted on the predicate type, is the bundle's domain schema.
* [The in-toto specification copy](attestation-copy.md) - The specification pages and protocol buffer definitions of the in-toto Attestation Framework at release v1.2.0, 26 files copied with the in-toto project's licence into `src/in_toto_linkml/schema/attestation/` and matched to that release by git object hash. The tests hold every field of the copied definitions to a slot of the schema.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and Java), the Python dataclasses and Pydantic models in `src/in_toto_linkml/datamodel/`, `docs/schema/` and `docs/elements/`, and `.lokf/in-toto.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: 42 valid examples and 54 counter-examples under `tests/data/`, one example waiting under `problem/valid/`, `tests/test_data.py`, which holds each to the validator, `tests/test_upstream.py`, which holds the schema to the specification copy, `tests/test_watch.py`, which runs the upstream watch against stubbed answers, and `tests/test_schema_rules.py`, which holds the adapt copy apart from LOKF and the eight neighbours' copies in `tests/neighbours/`.
