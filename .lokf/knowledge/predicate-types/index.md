# Predicate-types

* [Test Result](test-result.md) - The vetted in-toto predicate type Test Result, `https://in-toto.io/attestation/test-result/v0.1`: the results of one run of a test suite against the subjects: the result, the configuration, and the tests that passed, warned and failed. The schema models it as `InTotoTestResult`.
* [Simple Verification Result](simple-verification-result.md) - The vetted in-toto predicate type Simple Verification Result, `https://in-toto.io/attestation/svr/v0.1`: that a verifier evaluated the subjects against one or more policies, and which properties passed. The schema models it as `InTotoSimpleVerificationResult`.
* [SCAI Report](scai.md) - The vetted in-toto predicate type SCAI Report, `https://in-toto.io/attestation/scai/v0.3`: assertions about functional attributes of the subjects or their producer, each with its evidence. The schema models it as `InTotoScaiAttributeReport`.
* [Link](link.md) - The vetted in-toto predicate type Link, `https://in-toto.io/attestation/link/v0.3`: one step of an in-toto layout, its command and its materials, for migration from in-toto 0.9. The schema models it as `InTotoLink`.
* [Reference](reference.md) - The vetted in-toto predicate type Reference, `https://in-toto.io/attestation/reference/v0.1`: references from the subjects, as a whole, to documents about them. The schema models it as `InTotoReference`.
* [Release](release.md) - The vetted in-toto predicate type Release, `https://in-toto.io/attestation/release/v0.1`: that the subjects are the artifacts of one release name and version of a package. The schema models it as `InTotoRelease`.
* [Runtime Traces](runtime-trace.md) - The vetted in-toto predicate type Runtime Traces, `https://in-toto.io/attestation/runtime-trace/v0.1`: what a monitor traced while a supply chain step ran. The schema models it as `InTotoRuntimeTrace`.
* [VULNS](vulns.md) - The vetted in-toto predicate type VULNS, `https://in-toto.io/attestation/vulns/v0.2`: the result of a vulnerability scan of the subjects. The schema models it as `InTotoVulns`.
* [SLSA Provenance](slsa-provenance.md) - The vetted in-toto predicate type SLSA Provenance, `https://slsa.dev/provenance/v1`: how an artifact or set of artifacts was produced. lmodel/slsa models it.
* [SLSA Verification Summary](slsa-verification-summary.md) - The vetted in-toto predicate type SLSA Verification Summary, `https://slsa.dev/verification_summary/v1`: a SLSA verification decision about a software artifact. lmodel/slsa models it.
* [CycloneDX](cyclonedx.md) - The vetted in-toto predicate type CycloneDX, `https://cyclonedx.org/bom/v1.4`: a CycloneDX bill of materials for software artifacts. The schema names it by type URI only, since its body is another specification's document.
* [SPDX2](spdx2.md) - The vetted in-toto predicate type SPDX2, `https://spdx.dev/Document/v2.3`: an SPDX 2 bill of materials for software artifacts. The schema names it by type URI only, since its body is another specification's document.
* [SPDX3](spdx3.md) - The vetted in-toto predicate type SPDX3, `https://spdx.dev/Document/v3`: an SPDX 3 bill of materials for software artifacts. The schema names it by type URI only, since its body is another specification's document.
